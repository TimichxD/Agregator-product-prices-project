# «Выгодно»

Приложение для формирования корзины и сравнения ценовых предложений магазинов. Интерфейс выполнен на PyQt6; все разделы открываются в одном окне.

## Запуск

```bash
python -m pip install -r requirements.txt
python main.py
```

Для встроенной карты требуется `PyQt6-WebEngine`. При его отсутствии можно открыть карту в браузере.

## Загрузка каталога

В проект уже добавлен стартовый каталог `data/products.csv`: 21 товар в основных категориях с фотографиями. Для части товаров внесены предложения магазинов и цены из опубликованных сравнений. Остальные цены оставлены пустыми, если не было точного подтверждения. При запуске каталог загружается автоматически. Фотографии запрашиваются с внешних сайтов, поэтому для их отображения нужен интернет; если источник перестанет отдавать файл, приложение покажет нейтральную миниатюру.

Каталог не подтверждает наличие каждого товара в конкретной торговой сети. Источники фотографий перечислены в `data/PHOTO_SOURCES.md`, источники и даты внесённых цен — в `data/PRICE_SOURCES.md`.

Чтобы заменить или расширить каталог, нажмите **«Загрузить каталог CSV»** в разделе «Каталог». Пустой шаблон находится в `data/products_template.csv`. Столбцы:

| Столбец | Обязательный | Назначение |
|---|---:|---|
| `product_id` | Да | Уникальный код товара |
| `name` | Да | Название |
| `unit` | Да | Фасовка или единица измерения |
| `category` | Да | Категория |
| `store` | Для цены | Название магазина |
| `price` | Для магазина | Цена за единицу, например `129,90` |
| `image` | Нет | Путь к фото или HTTPS/HTTP-ссылка |

**Одна строка — одно предложение магазина.** Если товар продаётся в трёх магазинах, добавьте три строки с одинаковым `product_id` и разными `store` и `price`. Изображение можно указать в одной строке товара; приложение объединит предложения по коду товара.

Файл должен содержать строку заголовков в указанном выше формате. Для нескольких магазинов добавляйте по одной строке на каждое предложение товара.

### Фотографии товаров

В столбце `image` можно указать путь к локальному файлу или прямую ссылку на изображение. Локальные файлы при импорте копируются в `data/images`, поэтому после загрузки каталога исходную папку можно переместить. Также поддерживается автоматическое сопоставление: положите фото в `data/images` и назовите его по `product_id`, например `SKU-123.jpg`. Поддерживаются JPG, JPEG, PNG и BMP. Если фотография не найдена или ссылка недоступна, в каталоге останется нейтральная миниатюра.
