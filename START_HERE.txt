«Выгодно» — приложение для сравнения ценовых предложений и подбора корзины.

1. Установите зависимости:
   python -m pip install -r requirements.txt
2. Запустите приложение:
   python main.py
3. В каталоге уже загружен стартовый список из 21 товара с фотографиями.
4. Для загрузки актуальных предложений магазинов используйте «Загрузить каталог CSV». Формат описан в README.md, пустой шаблон — data/products_template.csv.
5. Источники фотографий указаны в data/PHOTO_SOURCES.md. Для загрузки изображений нужен интернет; если ссылка недоступна, останется нейтральная миниатюра.

Важно: список товаров не означает подтверждённое наличие в конкретной торговой сети. Часть ценовых предложений заполнена по опубликованным сравнениям магазинов Уфы. Источники и даты указаны в data/PRICE_SOURCES.md; остальные цены оставлены пустыми, если точного совпадения не найдено.
Все разделы работают в одном окне и используют общую корзину.
