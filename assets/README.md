# Изображения приложения

Фотографии продуктов загружаются из каталога пользователя: через столбец `image` в CSV или автоматически из `data/images/{product_id}.jpg` (также поддерживаются `.jpeg`, `.png` и `.bmp`). Локальные изображения из импортируемого CSV копируются в `data/images`, а изображения по HTTP/HTTPS загружаются асинхронно. Если файла нет или сеть недоступна, интерфейс показывает нейтральную миниатюру.

Фиктивные фотографии товаров в проект не добавлены: изображение должно относиться к реальному товару из загружаемого каталога.
